# Launch in English and Arabic

WANAS serves customers in Cairo and requires Arabic at launch. The first release supports English and Arabic, with right-to-left layouts for Arabic. Language support belongs in the initial interface and content model so Arabic speakers can complete the same booking flow at launch.

First-time visitors see Arabic. A language switch is available on every screen and the site remembers the choice. Translate the planner, catalog, dashboard, and notification emails. Admins write custom quote notes in the customer's chosen language.
