# WANAS design

WANAS pairs event-setting photographs with a planning workspace in Arabic and English. The first screen lets guests choose their occasion and start a brief. Quotes, bookings, and staff views put the next action alongside the information needed to take it.

## Color and type

Use the existing cream paper (`#fcf6f3`), blush (`#fae8df`), terracotta (`#98440e`), deep terracotta (`#773309`), and warm ink (`#261b16`). Use the deep terracotta for large areas and high-contrast actions. Use blush for selected states and keep the existing green and red for booking and error states.

Use EB Garamond for large public headlines, Manrope for controls and lists, and Noto Sans Arabic for Arabic text. Use logical layout properties so navigation, arrow directions, and content order follow the locale.

## Layout and interaction

- Home places the occasion selector next to one large photograph. The visitor controls the photographs, and each occasion example links to a matching planner entry.
- The planner shows the active stage, puts required decisions in reading order, and keeps the event summary separate. Every stage ends with the same action row.
- Customer requests use short records with status-specific actions. The detail page puts quotes and bookings before the brief and labels the customer's own inspiration links.
- Staff share one workspace navigation across the inbox, request details, calendar, and booking changes.
